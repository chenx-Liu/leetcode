# Longest Palindromic Substring

## Problem Description

Given a string `s`, return its longest palindromic substring.

A palindrome reads the same forward and backward. A substring is a contiguous sequence of characters within a string.

If multiple longest palindromic substrings exist, you may return any one of them.

## Examples

### Example 1

```text
Input: s = "babad"
Output: "bab"
Explanation: "aba" is also a valid answer.
```

### Example 2

```text
Input: s = "cbbd"
Output: "bb"
```
