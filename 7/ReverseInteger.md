# Reverse Integer

## Problem Description

Given a signed 32-bit integer `x`, reverse its decimal digits and return the resulting integer.

Keep the original sign, and omit any leading zeros in the reversed number.

If the reversed value is outside the signed 32-bit integer range `[-2^31, 2^31 - 1]`, return `0`.

Do not use signed or unsigned 64-bit integers to store intermediate results.

## Examples

### Example 1

```text
Input: x = 123
Output: 321
```

### Example 2

```text
Input: x = -123
Output: -321
```

### Example 3

```text
Input: x = 120
Output: 21
```
