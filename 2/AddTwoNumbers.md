# Add Two Numbers

## Problem Description

You are given two non-empty linked lists, `l1` and `l2`, representing two non-negative integers. Each node contains one digit, and the digits are stored in reverse order: the first node holds the ones digit, the second holds the tens digit, and so on.

Add the two numbers and return their sum as a linked list in the same reverse order.

The numbers have no leading zeros, except for the number zero itself.

## Examples

### Example 1

```text
Input: l1 = [2,4,3], l2 = [5,6,4]
Output: [7,0,8]
Explanation: The lists represent 342 and 465. Their sum is 807.
```

### Example 2

```text
Input: l1 = [0], l2 = [0]
Output: [0]
```

### Example 3

```text
Input: l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
Output: [8,9,9,9,0,0,0,1]
```
