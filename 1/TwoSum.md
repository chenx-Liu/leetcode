# Two Sum

## Problem Description

Given an array of integers `nums` and an integer `target`, find the indices of the two elements whose values add up to `target`.

Each input has exactly one valid answer, and you may not use the same element twice. You can return the indices in any order.

## Examples

### Example 1

```text
Input: nums = [2,7,11,15], target = 9
Output: [0,1]
Explanation: nums[0] + nums[1] = 2 + 7 = 9.
```

### Example 2

```text
Input: nums = [3,2,4], target = 6
Output: [1,2]
```

### Example 3

```text
Input: nums = [3,3], target = 6
Output: [0,1]
```
